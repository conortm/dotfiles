# Global Personal Memory

This file defines my cross-project preferences and technical standards. These rules apply to every workspace I enter.

## 🛠 Core Workflow
- **CLI-First:** I prefer terminal-based solutions over GUI-driven ones. 
- **Vim Proficiency:** I use Vim/Neovim keybindings; assume modal editing familiarity.
- **Git Aliases:** Always check `git status` before performing destructive operations.
- **Shell:** My primary environment is Bash on Linux.

## 💻 Coding Standards
- **Indentation:** Default to 2-space indentation for web technologies (JS/TS, HTML, CSS) and YAML/JSON.
- **Clean Code:** Prioritize intention-revealing names over comments. 
- **Testing:** I value high test coverage. Prefer `jest` for JavaScript and `pytest` for Python.
- **Surgical Edits:** When modifying code, keep changes focused and minimal to avoid unrelated churn.

## 🗣 Communication Style
- **Technical & Concise:** Keep explanations brief. Focus on the "why" and "how" rather than narrating every action.
- **Proactive Insights:** If you see a potential architectural improvement or a security risk, point it out before proceeding.
- **No Filler:** Skip conversational pleasantries and apologies; go straight to the technical solution.
